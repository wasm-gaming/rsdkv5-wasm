# Contract 1.0, standalone package and the engine's own storage folder

2026-11-12 · same migration as rsdkv4-wasm 0.3.0, blastem-wasm 0.2.0 and rsdkv3-wasm 0.2.0 (their
RECORD/ files of the same name).

**Status:** approved by the owner ("dale a blastem y luego a los rsdk"), being implemented.

## Where it is (verified at `0f65d02`, v0.1.1)

- Legacy `{ manifest, load }`, engine-specs `*`.
- Build already pinned (Sonic-Mania-Decompilation `9dc69942`, emsdk 6.0.2) — unchanged here.
- Working dir `/data/<namespace>` in memory; Mania's user files (`SaveData.bin`,
  `TimeAttackDB.bin`, `ReplayDB.bin`, `Replay_*.bin`, written to `userFileDir` = CWD) are
  **lost on reload**; namespace not prefixed by the engine.
- `engineDebugMode` option is declared but never used.

## Changes

- `Rsdkv5SDK` / `Rsdkv5Play` (`static id = 'rsdkv5'`), same shape as rsdkv3:
  config `devMenu`, `vsync`, `language`, `region` (→ generated `Settings.ini`, capital S),
  `jsUrl`, `wasmUrl`; assets `data` (required), `settings`; storage `namespace`, `persist`;
  events `saves`. `engineDebugMode` dropped (dead).
- Storage `rsdkv5/<namespace>/`: every file the game writes in the working dir (all but
  `Data.rsdk`, `Settings.ini`, `log.txt`) is seeded from OPFS before boot and mirrored back on change.
- Owner-aware pause/resume (engine bridge + SDL audio), `devMenu` bridge, `destroy()`.
- Self-contained ESM, engine-specs `^0.3.2` dependency, `CLAUDE.md -> AGENTS.md`, `RECORD/`,
  no-build demo, tests, workflows aligned (release asset `rsdkv5.tar.gz`, `rsdkv5/rsdkv5/`), 0.2.0.
